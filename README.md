# Spring Boot Backend Development – Internship Learning Repository

This repository contains the Spring and Spring Boot based backend practice projects developed during my internship at:

Role: Java Full Stack Developer Intern
Organization: Dyashin TechnoSoft Pvt Ltd
Duration: September 2025 – January 2026

The projects in this repository demonstrate the implementation of backend development concepts using the Spring ecosystem, including RESTful services, microservices architecture, service discovery, security, and configuration management.

## Internship Overview

During this internship, I worked on backend development using Spring Framework and Spring Boot to understand how modern Java applications are structured and deployed. The focus was on building scalable backend services and learning how different Spring components work together in real-world applications.

The repository includes multiple practice applications created to explore different Spring Boot features and microservices concepts.
